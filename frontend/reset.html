Application Reset Tools

Use these tools to reset the application state if you're experiencing issues with the login or registration functionality.

1. Clear Local Storage

This will clear all stored data including authentication tokens and user information.

2. Reset UI State

This will reset the UI state to its initial configuration.

3. Complete Reset

This will perform a complete reset of the application (clears storage and resets UI).
